📊 Fixed Deposit (FD) Calculator – Web Application

This project is a simple, responsive Fixed Deposit (FD) Calculator built using HTML, CSS, and JavaScript. It allows users to calculate the maturity amount of a fixed deposit by entering the principal amount, interest rate, and tenure in years.

The application performs real-time calculations on the client side using a straightforward financial formula, making it fast, lightweight, and easy to understand—especially for beginners learning JavaScript DOM manipulation and basic financial logic.

✨ Key Features

User-friendly and minimal UI

Real-time FD maturity amount calculation

Clean and responsive design

Pure Vanilla JavaScript (no external libraries)

Beginner-friendly code structure
